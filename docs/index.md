# Arrowz Browser

A small, fast, private web browser for Android TV, operable end to end with four
arrows, OK and BACK. It ships no analytics, blocks trackers out of the box, and
makes no request to us at any point.

Downloads, including a sideloadable APK for televisions the Play Store has not
reached, are on the [releases page](https://github.com/NoMercyLabs/Arrowz-Browser/releases).
